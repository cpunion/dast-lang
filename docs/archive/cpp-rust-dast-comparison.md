## 核心设计决策

### 借用检查: 完整实现 (无需生命周期标注)

```dast
// ✅ 函数内完整借用检查
let a = &mut arr[i]
let b = &mut arr[j]  // 编译错误: 可能重叠

// ✅ 跨函数自动推断
fn first(arr: &[i32]) -> &i32 {
    return &arr[0]  // 自动推断生命周期
}
```

### 无法推断的模式: 编译器禁止 (非安全问题)

```dast
// ❌ 编译错误 → 强制使用安全替代方案
fn longest(x: &str, y: &str) -> &str { ... }

// ✅ 安全替代
fn longest(x: &str, y: &str) -> String { ... }
```

**~3% 的 Rust 模式在 Dast 中无法表达，但都有安全替代方案**

## 唯一安全差距: 线程安全 (~2%)

| 方面 | Rust | Dast |
|------|------|------|
| 机制 | Send/Sync trait | @thread_safe 标记 |
| 覆盖率 | 100% | ~98% |
| 边缘情况 | ✅ 完全检测 | ⚠️ 复杂闭包可能漏检 |

## 表达力 vs 安全性

| 指标 | Rust | Dast |
|------|------|------|
| 安全性 | 100% | ~98% |

| 学习曲线 | 高 | 低 |
| 无法表达的模式 | 0% | ~3% (有安全替代) |

---

## 无法表达的 ~3% 模式

| 模式 | 频率 | 安全替代方案 |
|------|------|-------------|
| 多引用返回其一 | ~1% | 返回值/索引 |
| 多引用字段 | ~1% | 单引用/参数传递 |
| 生命周期约束 | ~0.5% | 拥有数据/Arena |
| 高阶生命周期 | ~0.2% | trait object |
| 自引用结构 | ~0.3% | @pinned + 索引 |

**这些不是安全问题，是表达力限制，编译器强制使用安全替代**

```
Dast = Rust 借用检查 - 生命周期标注 + 自动推断
     = 98% 安全 + 97% 表达力 + 低学习曲线
```
