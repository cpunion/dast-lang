# 目标平台矩阵

## 平台分类

### 1. 嵌入式裸机 (Bare Metal)

| 目标架构 | 典型设备 | 关键约束 |
|---------|---------|---------|
| ARM Cortex-M0/M3/M4 | STM32, nRF52 | 无 OS、KB 级内存、无标准库 |
| RISC-V RV32IMC | ESP32-C3 | 极小 Flash、严格功耗 |
| AVR | Arduino (低端) | 8-bit、极限资源 |

**编译要求**:
- 自定义链接脚本
- 无堆分配模式 (`--no-heap`)
- 中断向量表生成
- 栈使用静态分析

### 2. 边缘计算

| 目标架构 | 典型设备 | 关键约束 |
|---------|---------|---------|
| ARM64 (AArch64) | Raspberry Pi 4/5, Jetson | Linux、受限内存 |
| RISC-V RV64GC | VisionFive 2, Milk-V | Linux、新兴生态 |
| x86_64 | 工控机、网关 | Linux/Win、相对充裕 |

**编译要求**:
- 静态链接优先 (musl libc)
- 最小化依赖
- 交叉编译支持

### 3. 主机平台

| 操作系统 | 架构 | 特点 |
|---------|------|------|
| Linux | x86_64, ARM64 | 完整功能、动态链接可用 |
| macOS | ARM64 (Apple Silicon), x86_64 | Metal 原生支持 |
| Windows | x86_64, ARM64 | DirectX 原生支持 |

**编译要求**:
- 动态库生成 (.so/.dylib/.dll)
- 调试信息 (DWARF/PDB)
- 包管理器集成

### 4. WebAssembly

| 运行环境 | 特点 |
|---------|------|
| 浏览器 | WebGL/WebGPU、JS 互操作、异步限制 |
| WASI (命令行) | 文件系统、网络 (受限) |
| 嵌入式 WASM 运行时 | Wasmtime, Wasmer, WasmEdge |

**编译要求**:
- WASM32 目标
- 极限体积优化 (wasm-opt)
- JS 胶水代码生成
- 多内存/多线程 (当可用时)

### 5. 移动端

| 平台 | 架构 | 特点 |
|------|------|------|
| iOS | ARM64 | Metal、沙箱、App Store 限制 |
| Android | ARM64, x86_64 (模拟器) | Vulkan/OpenGL ES、NDK 集成 |

**编译要求**:
- 静态库 (.a) 输出
- 与 Swift/Kotlin 互操作
- 资源打包
